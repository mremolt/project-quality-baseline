# Solution Strategy: TypeScript

The key technology decisions for TypeScript components. They tighten the shared strategy in [04-solution-strategy/README.md](README.md) and never contradict it. Navigation and skills for this stack: [stacks/typescript.md](../stacks/typescript.md).

## Defaults

These tighten the shared defaults ([04-solution-strategy/README.md](README.md)) for TypeScript:

| # | Topic | Default | Defined in |
|---|---|---|---|
| TS-D1 | Async in ports | `Promise` (with optional `AbortSignal`); `Observable` only for real streams (WebSocket, SSE) | [05-building-block-view/typescript.md](../05-building-block-view/typescript.md) |
| TS-D2 | Schema library | zod (generated by Orval for API types, hand-written for commands) | [05-building-block-view/typescript.md](../05-building-block-view/typescript.md) |
| TS-D3 | Compiler, browsers | `strict` plus extra checks; supported browsers = Baseline widely available at a date the baseline fixes (currently 2026-05-07); `target`/`lib` at the newest level they all support (`ES2023`), wider via ADR | [08-crosscutting-concepts/development/typescript-tooling.md](../08-crosscutting-concepts/development/typescript-tooling.md) |
| TS-D4 | Lint | ESLint with typescript-eslint `strictTypeChecked` + `stylisticTypeChecked`, SonarJS, import-x, simple-import-sort | [08-crosscutting-concepts/development/typescript-tooling.md](../08-crosscutting-concepts/development/typescript-tooling.md) |
| TS-D5 | Format | Prettier, `printWidth: 120` | [08-crosscutting-concepts/development/typescript-tooling.md](../08-crosscutting-concepts/development/typescript-tooling.md) |
| TS-D6 | Unit tests | Vitest + vitest-mock-extended | [08-crosscutting-concepts/testing/typescript.md](../08-crosscutting-concepts/testing/typescript.md) |
| TS-D7 | E2E | Playwright, two tiers (stubbed backend / real backend smoke) | [08-crosscutting-concepts/testing/typescript.md](../08-crosscutting-concepts/testing/typescript.md) |
| TS-D8 | API clients | Orval, generated from the pinned spec (the backend's file in the same repo, a pinned copy otherwise) | [08-crosscutting-concepts/api/typescript-openapi-clients.md](../08-crosscutting-concepts/api/typescript-openapi-clients.md) |
