## TypeScript defaults

These tighten the shared defaults ([shared/README.md](../shared/README.md)) for TypeScript:

| # | Topic | Default | Defined in |
|---|---|---|---|
| TS-D1 | Async in ports | `Promise` (with optional `AbortSignal`); `Observable` only for real streams (WebSocket, SSE) | frontend-architecture.md |
| TS-D2 | Schema library | zod (generated by Orval for API types, hand-written for commands) | frontend-architecture.md |
| TS-D3 | Compiler | `strict` plus extra checks, target `ES2025` | tooling.md |
| TS-D4 | Lint | ESLint with typescript-eslint `strictTypeChecked` + `stylisticTypeChecked`, SonarJS, import-x, simple-import-sort | tooling.md |
| TS-D5 | Format | Prettier, `printWidth: 120` | tooling.md |
| TS-D6 | Unit tests | Vitest + vitest-mock-extended | testing.md |
| TS-D7 | E2E | Playwright, two tiers (stubbed backend / real backend smoke) | testing.md |
| TS-D8 | API clients | Orval, generated from the pinned spec (the backend's file in the same repo, a pinned copy otherwise) | openapi-clients.md |
